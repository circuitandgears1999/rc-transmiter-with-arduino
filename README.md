This project is a ** rc controller built with Arduino  **.  
its a **12 channel rc controller**, giving it a unique look and making it a fun electronics build for beginners and hobbyists.

---

## ✨ Features
- 12 channel radio controll
- 1km range 
- Compact and **easy to assemble**
- Uses **basic and affordable Arduino components**
- Simple, clean and reliable operation

---

## 🧰 Components Required

2 arduino pro mini
2 joystic module
2 NRF24L01
2 10k potentiometer
3.3v and 5v power modules
5v buck converter module
4 12X12 switches
on/off switch
4 10k Resistors
project board and pin headers

---

## 🚀 How to Use
1. Connect all components as shown in the provided circuit diagram.  
2. Upload the Arduino code to your arduino boards.  
3. Power it up !  
4. Use the buttons and joystic to send data to your reciver.
